# hyperhelvetica-vote

Vote endpoint for [konrads.link/Hyperhelvetica](https://konrads.link/Hyperhelvetica/): a Cloudflare
Worker with one D1 table. The page is static and lives in `public/Hyperhelvetica/`. Its card images,
ballot data (`designs.js`) and the design tool are generated by `~/Claude/hyperhelvetica/flag/publish-vote.mjs`;
`index.html` is handwritten.

## Rules

- One vote per browser. The page keeps a random id in localStorage and sends it with the vote; a repeat gets
  409 and the results.
- At most `NETWORK_DAILY_CAP` (10) votes per network per UTC day, so an office or household can all vote but a
  script cannot flood it. A network is a salted SHA-256 of the connecting IP (`IP_SALT` secret). Raw IPs are
  never stored.
- Only `ALLOWED_ORIGINS` can cast votes.
- Results go only to a browser that has voted, until `VOTING_OPEN` is `"false"`. Then new votes are refused
  and the page shows the final results to anyone who tries to vote.

## Test

    npm install
    npm test            # endpoints, against wrangler dev with a throwaway local D1
    npm run test:page   # the page in headless Chromium; run publish-vote.mjs first

Both suites use port 8787 and `.wrangler/test-state`, so run them one after the other. `SHOTS=<dir>` keeps
the page screenshots. Local runs need a `.dev.vars` file (gitignored):

    IP_SALT=anything
    ALLOWED_ORIGINS=https://konrads.link,http://localhost:4321,http://127.0.0.1:4321

## Deploy (first time)

    npx wrangler login
    npx wrangler d1 create hyperhelvetica-vote        # put the database_id into wrangler.toml
    npx wrangler d1 migrations apply hyperhelvetica-vote --remote
    openssl rand -hex 32 | npx wrangler secret put IP_SALT
    npx wrangler deploy                               # prints the workers.dev URL

Then set that URL as `DEPLOYED_API` in `public/Hyperhelvetica/index.html` and push the site. Until then the
live page shows the four designs with "Voting opens soon." and no vote buttons.

## Running the vote

Tally, with the full design by colour split:

    npx wrangler d1 execute hyperhelvetica-vote --remote --command "SELECT design, colour, COUNT(*) AS n FROM votes GROUP BY design, colour ORDER BY design, colour"

Votes per day:

    npx wrangler d1 execute hyperhelvetica-vote --remote --command "SELECT day, COUNT(*) AS n FROM votes GROUP BY day ORDER BY day"

Close the vote: set `VOTING_OPEN = "false"` in `wrangler.toml`, then `npx wrangler deploy`.

Live logs: `npx wrangler tail`.
