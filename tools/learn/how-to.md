This is a private, self-paced copy of the [Fractal Bootcamp](https://github.com/fractal-nyc/bootcamp-monorepo) curriculum: ten intense weeks of software engineering with AI, rearranged so you can work through it a bit at a time.

## The path

- **Path** is the main sequence: Start here, then Weeks 1–8, then the capstone. Each week has readings, assignments and lecture notes. Lessons marked *optional* are extras, often an older cohort's version of the same week.
- **Practice** holds the scales (short drills for 20–45 spare minutes) and the library of every reading.
- The bootcamp assumes you build things. Most assignments fork a starter repo from [github.com/fractal-bootcamp](https://github.com/fractal-bootcamp) and ask you to ship code, so keep a code editor and a terminal nearby.

## Working bit by bit

- On **Today**, say how much time you have and the app suggests what fits: one reading or a scale for 25 minutes, the next section of an assignment for an hour or two, a whole assignment for a half day.
- Tick checkboxes as you finish steps, and mark each section done with the ✓ beside its heading. Progress, the next suggestion and "continue where I left off" all follow from those ticks.
- Press **Start session** on a lesson to time yourself. When you stop, write one line about what you did. The bootcamp asked everyone for an end-of-day note with wins, blockers and links; the **Journal** collects yours.
- Each lesson has a notes box and a place for the link to your repo or PR.

## Getting help from Claude

- In **Settings**, *Copy progress for Claude* puts a plain-text summary on your clipboard: where you are, what's done, your recent journal and the notes for your current lesson. Paste it into a chat with Claude and ask for help with the next step.
- The bootcamp's rule still applies: let Claude explain, but write the code yourself, at least in the early weeks.

## Privacy

- Everything here is encrypted with your passphrase (AES-256-GCM, with the key derived by PBKDF2-SHA256 at 600,000 iterations). The server only ever holds ciphertext, and the passphrase never leaves your browser.
- Your progress is saved in this browser, encrypted, on every change. To use another device, either turn on sync (if it's set up; see Settings) or export an encrypted backup and import it there.
- **Lock** clears the keys from memory. "Remember this device" keeps a non-exportable key in this browser so you don't have to retype the passphrase; leave it off on shared computers.
- If you forget the passphrase, the data cannot be recovered, by you or anyone else.
